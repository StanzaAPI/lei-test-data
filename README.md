# LEI Test Data

Twenty-character LEIs with a correctly computed ISO 7064 MOD-97-10 check-digit pair. Synthetic entities; not registered organisations.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

## Files

- `lei-small.json`
- `lei-small.csv`
- `lei-medium.json`
- `lei-medium.csv`
- `lei-large.json`
- `lei-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
